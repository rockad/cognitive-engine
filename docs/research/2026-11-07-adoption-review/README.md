## Labels

Every claim carries a label:

- **verified** (V, VOD): read in source or official docs, with file and line
- **reported** (R): from a README or a third party only
- **unverified** (U): inferred

## Clones and limits

- External repositories were cloned shallow into a scratch area and never built or run. Those `/tmp/...` paths no longer exist.
- File and line references point at the commit named at the top of each report.
- Some vendor sites were unreachable from the session. Each report says which.
